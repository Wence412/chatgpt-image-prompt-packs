# Contributing

Suggested contribution format:

1. Add the prompt to `data/prompts.json`.
2. Include phase, category, title, prompt, best_for, framework, and tags.
3. Keep prompts commercially usable, specific, and brand-safe.
4. Avoid real-person likeness requests unless a user-provided reference is available and permitted.
5. Avoid copyrighted characters, real logos, and random generated text unless explicitly supplied.
