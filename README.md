## 🎓 The S.E.E.D. Framework

Every production prompt follows this proven structure:

| Element | Purpose | Example |
|---------|---------|---------|
| **S**ubject | Hero object/person/scene | Product, founder, AI character |
| **E**lements | Props, materials, visual cues | Packaging, outfit, typography |
| **E**nvironment | Setting/context | Studio, lifestyle, retail shelf |
| **D**etails | Lens, lighting, style, constraints | f/1.8, soft shadows, no text |

**Result:** Consistent, repeatable, commercially-ready visuals.

📖 [Read full S.E.E.D. guide](docs/seed-framework.md)

### 🎬 Before & After Workflow
Test your prompts with real examples:

### 📊 Ad Testing Matrix
Optimize performance with systematic variation:
- Change **1 variable** at a time
- Keep everything else **consistent**
- Track what wins
- Scale the winners

[View testing matrix](examples/ad-testing-matrix.md)

### ✅ Production Checklist
Before delivering to clients:
```
✓ Solves a clear marketing problem?
✓ Subject immediately recognizable?
✓ Brand consistent across series?
✓ Clean space for copy?
✓ Realistic proportions & shadows?
✓ No random text or errors?
✓ Fits the platform?
✓ Style repeatable for campaigns?
✓ Prompt documented?
✓ Commercially ready?
```
