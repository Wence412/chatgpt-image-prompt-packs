# Before and After Workflow

Use this workflow to demonstrate the value of detailed prompting.

1. Generate a basic version with a short prompt.
2. Generate a production version using S.E.E.D.
3. Compare clarity, composition, lighting, brand fit, and usability.
4. Document the improved prompt as the reusable production prompt.

## Example

Basic prompt:

```text
Create a coffee product mockup.
```

Production prompt:

```text
Create a photorealistic standalone coffee product mockup resting on a natural stone surface. Bathe the scene in soft directional morning sunlight with realistic shadows and cinematic depth of field. Keep a clean singular focus. Strictly no labels unless supplied, no grids, and no split-screen layouts.
```
